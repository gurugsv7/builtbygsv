# BuiltbyGSV Page Plan

This plan is for pages that should be designed and written manually. The goal is not to create many city/keyword pages. The goal is to create a small set of useful pages with real proof, clear services, and strong identity signals for BuiltbyGSV, GuruGSV, Guru GSV, and Gurusabarivasan M.

## Page Types

### Core Pages

These are important for both users and Google. They explain who you are, what you do, and why someone should trust you.

### SEO Service Pages

These target service searches like website developer, software developer, AI solutions, and business automation. They must still be useful and specific.

### Local SEO Pages

These target location-based searches. Keep them few and strong. Do not duplicate the same page with only the city name changed.

### Proof Pages

These are project/case-study pages. They are the strongest trust signal because they show real work.

### Info / Blog Pages

These answer real questions people search before hiring a developer. They should be written from experience, not generic AI content.

## Quality Rules

- Write from real experience.
- Use screenshots, project proof, and specific examples.
- Keep each page useful even if Google did not exist.
- Do not repeat the same paragraphs across location pages.
- Use the names consistently: BuiltbyGSV, GuruGSV, Guru GSV, Gurusabarivasan M.
- Avoid fake awards, fake reviews, fake addresses, and inflated results.
- Prefer one strong page over five weak pages.
